# Tibo X 投稿監視メモ

確認日: 2026-06-17

Tibo 氏の X 投稿は、Codex のリセット予告や障害・容量到達・rate limit 異常の早期シグナルになり得る。

## 方針

- 本番反映前に、取得手段の安定性と運用リスクを確認する。
- 公開リポジトリには、取得先の詳細な検証コードや失敗ログを置かない。
- 公式予告や障害対応らしい投稿を確認した場合は、まず手動で `official_notice` / `official_incident_hint` の候補として扱う。
- 自動連携は、取得成功率・遅延・誤検知の確認ができてから検討する。

## 現時点の判断

X 公式 API を使わない無料の公開取得手段だけで、Tibo 氏の最新投稿を安定取得できる方法は未確定。

そのため、現段階では本番予測の主要入力にはしない。重要投稿を確認した場合だけ、履歴・観測シグナルとして手動追加する。

## 分類方針

投稿を確認できた場合は、まず以下のように候補分類する。

- `official_notice`: リセット予告、利用上限リセット、24時間以内の実施予告
- `official_incident_hint`: 容量到達、rate limit 異常、高エラー率、利用上限まわりの異常

否定文脈や冗談・引用だけの投稿は、予測材料にしない。

## 次のステップ案

1. 重要投稿は手動で観測シグナルへ反映する。
2. 自動取得は非公開環境で検証する。
3. 安定して取得できる方法が見つかったら、公開コードへ入れる前に運用リスクを再確認する。
