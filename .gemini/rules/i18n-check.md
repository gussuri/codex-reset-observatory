# i18n 多言語翻訳・完全性遵守ルール

観測所のテキストやシグナルを更新・追加する際は、以下のルールを必ず遵守すること。

## 必須手作業手順

1. **データ追加時**:
   `data/observationSignals.ts` や `data/resetHistory.ts` へ新しいシグナルや理由文章 (`boostReason`, `title`, `note` 等) を追加した場合、**直ちに `lib/radar/i18n.ts` の `DYNAMIC_TRANSLATIONS` へ `ja`, `en`, `zh` の3言語すべてのエントリーを追加登録すること**。

2. **多言語チェックの自動検証**:
   変更後は必ず `npm test` を実行すること。
   `tests/i18nCompleteness.test.ts` が自動的に全シグナル・全履歴・全ビューモデルの日本語漏れを機械検知し、PASS することを確認すること。

3. **表示文の二重チェック**:
   英語 (`en`) または 中国語 (`zh`) のビルド結果において、日本語文字（漢字・ひらがな・カタカナ）が未翻訳のまま残留していないことを確認すること。
